## Описание

Датасет содержит данные обо всех значительных землетрясениях магнитудой $\geq 2{,}5$, зарегистрированных USGS с 1900 года, — более 1 миллиона событий за 126 лет сейсмической истории.

Данные получены напрямую из API каталога землетрясений USGS (ключ API не требуется). Для соблюдения лимита в 20 000 событий за запрос и полного сбора данных с 2000 года используются запросы по полугодовым периодам.

## Ключевые статистики

- **Количество землетрясений:** 1 054 000+
- **Диапазон дат:** 1900 — настоящее время
- **Землетрясения магнитудой ≥ 8:** 120+ (включая Чили, 1960 г., $M9{,}5$ и Японию, 2011 г., $M9{,}1$)
- **Землетрясения магнитудой ≥ 7:** 1 100+
- **Покрытие:** глобальное, с отчётливыми паттернами в зонах:
  - Тихоокеанского огненного кольца (Ring of Fire)
  - Срединно‑Атлантического хребта (Mid‑Atlantic Ridge)
  - Альпийско‑Гималайского пояса (Alpide Belt)

## Структура данных

Файл: `earthquakes_1900_2026.csv` (1 061 343 уникальных записей)  
Формат: одна строка — одно событие  
Координаты: WGS84  
Временные метки: UTC  
Типы магнитуд: варьируются по эпохам и сетям (старые события — mb/ms, современные — преимущественно mw)

### Список колонок

| Колонка | Описание | Примерные значения |
|--------|----------|------------------|
| `id` | Уникальный идентификатор события USGS | `cent19000105190000000` |

## Варианты использования

- Геопространственный анализ и визуализация тектонических границ
- Прогнозирование магнитуд с помощью машинного обучения
- Проверка закона Гутенберга‑Рихтера
- Моделирование сейсмической опасности и рисков
- Анализ временных рядов частоты землетрясений
- Кластеризация для обнаружения границ тектонических плит (например, DBSCAN)
- Исследования и образование в области природных катастроф

## Примечания

Рост числа зарегистрированных событий на протяжении десятилетий отражает улучшение глобальной сети сейсмографов, а не реальное увеличение сейсмической активности.
